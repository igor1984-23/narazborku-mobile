# Capacitor wrapper for narazborku.ru

This repo wraps our Next.js site as a native Android WebView app.

**To build the APK, do this locally on a workstation with Android SDK:**

### One-time setup (1-2 hours)

```bash
# 1. Install Android Studio
#    https://developer.android.com/studio
#    During setup, install: Android SDK 34, Build Tools 34, NDK 26b

# 2. Install Java 17 (required for AGP 8+)
choco install -y temurin17jdk
# or download from https://adoptium.net/

# 3. Clone this repo
git clone https://github.com/igor1984-23/narazborku-mobile.git
cd narazborku-mobile
npm install
```

### Build APK (5-10 min)

```bash
# Build the web bundle
mkdir -p ../narazborku/web && cd ../narazborku/web
npm install
npx next build

# Copy built assets to Capacitor's www/
cd ../../narazborku-mobile
rm -rf www
mkdir -p www
cp -r ../narazborku/web/.next/static/. www/
# Also copy server-rendered HTML pages
for f in ../narazborku/web/.next/server/app/*.html; do
  if [ -f "$f" ]; then
    cp "$f" "www/server/$(basename $f)"
  fi
done

# Add Android platform and build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

### Upload to narazborku.ru

```bash
scp android/app/build/outputs/apk/debug/app-debug.apk user@narazborku.ru:/home/hermes/razborki-market/web/public/downloads/narazborku.apk
```

After upload, the APK is available at https://narazborku.ru/downloads/narazborku.apk

### Production build (signed)

For a release build, generate a keystore:

```bash
keytool -genkey -v -keystore narazborku.keystore -alias narazborku -keyalg RSA -keysize 2048 -validity 10000
```

Configure signing in `android/app/build.gradle`, then run `./gradlew assembleRelease`.
The signed APK is at `app/build/outputs/apk/release/app-release.apk`.

## File structure

```

├── capacitor.config.ts     # AppId, webDir, Android config
├── package.json             # @capacitor/{core,cli,android}
├── www/                      # Built web assets (gitignored)
├── out/                      # Placeholder for static export
└── android/                  # Generated by `npx cap add android` (gitignored)
```
